07 / GET STARTED 开始之前

先说清楚，
再开始。

关于安装、使用与选择。

什么样的 Mac 可以使用？+

支持 Apple Silicon（M 系列芯片），兼容目标为 macOS 14 或更新版本。Intel Mac 暂不支持。当前版本在 M2 Pro 16 GB、macOS 26.5.2 验证；macOS 14 尚无真机验证。系统语音识别选项需要 macOS 26。

可以直接下载吗？第一次怎么打开？+

当前 v2.3.1 通过 NextThought GitHub 仓库的 Releases 分发，需要仓库访问权。DMG 约 18 MB。应用沿用项目签名，尚未完成 Apple Developer ID 公证；首次打开若被系统拦截，请在「系统设置 → 隐私与安全性」确认来源后选择「仍要打开」。

一定要下载 OCR 和向量模型吗？+

不需要。语音识别和对话服务是核心；OCR 增强与语义检索是独立的可选能力。默认使用系统 OCR，资料仍可通过关键词检索。全部可选模型约 1.88 GB，另有约 186 MB 的文档运行包；安装占用与下载体积不同。Office 结构提取也需要该运行包，由应用管理，无需手动安装 Python。

回答需要联网或付费账号吗？+

默认本机语音识别不需要联网。回答需要配置可用的服务：支持本机 CLI（Codex）和兼容 API，也可连接兼容的本机推理服务。账号、网络、计费和额度规则照常适用，质量与速度取决于所选模型和硬件。

不开启语义检索，会把全部资料发给 AI 吗？+

不会。当前实现按统一的资料切片做关键词检索，再把命中片段纳入回答。开启向量检索后，会增加语义召回，更容易找到近义表达，但需要下载模型、占用内存并建立索引。实时语义检索等待超时会采用关键词结果。

开始录音和转写前需要做什么？+

开始录音或转写前，请先征得与会者同意，并遵守会议的隐私要求。可在设置中选择声音来源和适用的语音识别方式。
